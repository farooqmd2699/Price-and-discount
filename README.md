# Price and Discount

An offline-friendly pricing calculator for Printshoppy products.

Calculate discounted printing cost, shipping, packaging, payment fees and profit. Optional editable estimates account for packed weight, box dimensions and delivery area.

Open index.html in a browser to use it locally.

## GitHub Pages

In this repository, open Settings > Pages. Choose Deploy from a branch, select main and / (root), then Save.

The site will be available at https://farooqmd2699.github.io/Price-and-discount/ after deployment.

Shipping estimates are planning allowances, not live courier quotes.
